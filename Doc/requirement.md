# 🚀 Project Hub — 开发者项目管理器 功能设计文档 v5.0

---

## 📌 一、产品概述

### 1.1 产品定位

面向开发者与专业用户（律师、建筑师、设计师等）的多平台资源管理工具，统一管理项目、工具、文档、文件夹，支持分组、标签、快速启动、垃圾清理、职业模板与 AI 智能辅助，全面提升多项目开发与日常工作效率。

### 1.2 目标用户

* 使用 Visual Studio / Android Studio / CLion 等 IDE 的开发者
* 同时维护多个不同类型项目的程序员
* 律师、建筑师、设计师等需要以"项目/案件/客户"为单位管理文件的专业用户
* 需要统一管理工具、文档、文件夹入口的普通用户

### 1.3 核心价值

* 统一管理多类型项目 / 工具 / 文档 / 文件夹入口
* 一键启动单个项目或整套项目包
* 垃圾文件安全清理，释放磁盘空间
* 职业模板支持，开箱即用
* AI 智能辅助，长期演进为智能工作助手

## 🟢 三、MVP 功能（第一版必须实现）

### 3.1 项目 & 资源管理（多类型支持）

#### 支持的项目类型

| 类型 | 识别方式 | 默认启动方式 |
|------|----------|-------------|
| Visual Studio | `.sln` | `devenv.exe` |
| Android | `build.gradle` / `settings.gradle` | Android Studio |
| C++ | `CMakeLists.txt` / `Makefile` / `.vcxproj` | CLion / VS / VSCode（可配置） |
| 通用工具 | `.exe` / 任意可执行文件 | 直接运行（如 Postman、Navicat） |
| 通用文档 | `.xlsx` / `.docx` / 自定义后缀 | 系统默认程序 / 自定义程序 |
| 文件夹 | 任意目录路径 | 资源管理器打开 |

#### 通用文档 & 工具支持

* 支持添加任意文件，不限于代码项目
* 内置常见后缀识别：`.xlsx` / `.docx` / `.pdf` / `.pptx` 等
* **自定义后缀**：用户可添加后缀（如 `.postman_collection` / `.dwg` / `.rvt`）
* **自定义打开方式**：为每种后缀或每个文件指定打开程序（覆盖系统默认）

#### 数据字段（通用）

* 项目名称
* 项目类型
* 文件路径（入口文件或根目录）
* 最近打开时间 / 最后修改时间
* 使用时长（累计）/ 启动次数
* 所属分组 / 标签列表
* 备注 / 描述
* 自定义图标 / 颜色
* 占用空间（可选显示）
* 截止日期（可选）
* 关联客户 / 联系人（可选）
* 附件列表（关联资料路径）

---

### 3.2 项目列表展示

* 按项目类型图标区分（支持自定义图标 / 颜色）
* 展示：项目名称、类型、路径、最近打开时间
* **可选显示占用空间**（懒加载，默认关闭）
* 支持列表视图 / 卡片视图
* **最近使用 Tab**：展示最近打开的所有记录（跨类型）

---

### 3.3 启动系统

#### 单个启动

* 点击项目用对应 IDE / 程序打开
* 记录最近打开时间、启动次数、使用时长

#### 多项目批量启动

* 勾选多个项目 → 批量启动
* 支持启动顺序（拖拽排序）和间隔时间（0 ~ 10 秒）

#### 项目包（Project Bundle）

* 将多个项目 / 工具 / 文档 / 文件夹组合为一个项目包
* 一键启动整套环境，按预设顺序和间隔依次启动
* 支持项目包独立命名、标签、自定义图标
* 包内成员可单独启动，也可整包启动
* 支持将项目包配置保存为**模板**，快速复用（见 § 七）

---

### 3.4 标签系统

* 为项目 / 工具 / 文档 / 项目包添加多个标签
* 支持按标签筛选
* 标签全局管理（重命名、合并、删除）

---

### 3.5 分组管理

* 创建分组，支持折叠 / 展开
* 项目 / 项目包归类到分组

---

### 3.6 搜索与筛选

* 按名称 / 路径 / 备注 / 客户名称搜索
* 按项目类型 / 标签 / 分组筛选
* **全局搜索**：`Alt+Space` 呼出，直接搜索并启动，无需打开主界面

---

### 3.7 项目图标 & 颜色自定义

* 为每个条目设置自定义图标（上传图片 / 内置图标库）
* 设置颜色标签，视觉区分直观
* 项目包同样支持

---

### 3.8 项目记录删除与清理

* 删除单个 / 批量删除项目记录
* 清理无效路径（文件 / 目录已不存在）

## 📂 四、文件感知 & 系统集成

### 4.1 打开文件时自动感知

* 当用户打开一个文件 / 项目，若该路径不在 Project Hub 中，弹出提示询问是否加入
* 用户可选择：
  * 加入（选择分组 / 标签）
  * 本次忽略
  * 永久忽略该路径
* 支持在设置中开启 / 关闭此功能（默认开启）
* 感知范围可配置（仅监听特定类型文件，避免频繁弹出）

---

### 4.2 系统右键菜单集成

* 在 Windows 资源管理器中注册右键菜单选项「加入 Project Hub」
* 支持对象：文件、文件夹、`.exe` 等任意条目
* 右键后可直接选择加入到哪个分组 / 标签，无需打开主程序
* 支持在设置中开启 / 关闭右键菜单注册

## 🧹 五、垃圾文件清理

### 5.1 垃圾目录规则

#### Visual Studio / C++ 项目

| 目录 / 文件 | 说明 |
|------------|------|
| `/bin` | 编译输出（exe / dll） |
| `/obj` | 中间编译对象文件 |
| `/Debug` / `/Release` | 构建配置输出 |
| `/x64` / `/x86` | 平台构建输出 |
| `/.vs` | VS 隐藏缓存 |
| `/_ReSharper.Caches` | ReSharper 缓存 |

#### Android 项目

| 目录 | 说明 |
|------|------|
| `/build` | Gradle 构建输出 |
| `/.gradle` | Gradle 缓存 |
| `/app/build` | App 模块产物 |
| `/captures` | Android Studio 录制 |
| `/.idea`（可选） | IDE 配置 |

#### C++（CMake）项目

| 目录 / 文件 | 说明 |
|------------|------|
| `/build` | CMake 构建目录 |
| `/cmake-build-debug` | CLion Debug 构建 |
| `/cmake-build-release` | CLion Release 构建 |
| `CMakeCache.txt` | CMake 缓存文件 |
| `CMakeFiles/` | CMake 中间文件 |

---

### 5.2 占用空间展示

* 列表 / 卡片可选显示「项目总占用」和「可清理大小」
* 懒加载，进入详情或手动刷新时计算（默认关闭）

---

### 5.3 清理操作流程

1. **选择范围**：单个 / 选中 / 所有项目
2. **扫描预览**：列出将被删除目录及大小，**不直接删除**
3. **用户确认**：勾选要清理的目录（全选 / 反选）
4. **执行清理**：删除所选内容，显示释放空间
5. **清理报告**：本次共释放 X GB

---

### 5.4 删除匹配排除规则

* **文件名匹配**：指定文件名，所在目录跳过
* **通配符匹配**：支持 `*.json` / `*.xml` / `keep_*` 等
* **路径关键字**：路径含指定字符串则跳过
* **全局规则 & 单项目规则**分别管理
* 预览界面标注「因规则跳过」的条目

---

### 5.5 清理预设方案

| 预设 | 清理内容 |
|------|----------|
| 轻度清理 | 仅 `/obj`、`CMakeFiles/`、`CMakeCache.txt` |
| 标准清理 | 轻度 + `/bin`、`/build`、`/.gradle` |
| 深度清理 | 标准 + `/.vs`、`/Debug`、`/Release`、`/captures` |
| 自定义 | 用户自定义勾选，可保存为新预设 |

---

### 5.6 清理安全机制

* 所有删除须经用户预览确认，**禁止静默删除**
* **白名单**：目录加入保护名单，永不清理
* **回收站模式**（可选）：移至回收站而非直接删除

---

### 5.7 清理统计

* 每个项目可清理空间展示
* 历史清理记录（时间 / 释放大小）
* 整体磁盘释放汇总

## 📁 六、项目管理深化

### 6.1 项目归档

* 将不活跃项目归档，隐藏于主界面
* 归档项目可随时恢复
* 支持「归档」Tab 单独查看所有归档内容
* AI 可根据使用频率主动建议归档（远期）

---

### 6.2 项目克隆 / 模板

* 将项目包的结构（分组、成员类型、标签）另存为模板
* 从模板快速创建同类型新项目包（只需替换路径）
* 内置职业模板（见 § 九）：律师案件模板、建筑项目模板等
* 用户可自定义并保存模板

---

### 6.3 截止日期 / 提醒

* 为项目设置截止日期
* 临近时在主界面、托盘或系统通知提醒
* 支持自定义提前提醒天数（如提前 3 天 / 7 天）
* 可设置重复提醒或一次性提醒

---

### 6.4 文件变动监听

* 监听项目目录文件变动
* 在列表中显示「上次修改时间」
* 帮助判断项目是否活跃
* 有变动时可选在主界面或托盘提示

---

### 6.5 快速预览

* 选中文件条目时侧边栏预览内容：
  * 图片：直接显示
  * PDF：显示首页缩略图
  * 文本 / Markdown：显示前几行 / 渲染预览
  * Office 文档：显示首页缩略图（如系统支持）
* 开发者项目：侧边栏预览 `README.md`（Markdown 渲染）

---

### 6.6 附件 / 关联资料

* 为项目附加任意文件作为「关联资料」
* 不移动原文件，只记录引用路径
* 附件支持分类命名（如：合同 / 设计稿 / 会议记录）
* 一键打开附件

---

### 6.7 项目备份提醒

* 检测项目是否有 Git 仓库或云盘同步
* 长时间未备份时提醒用户
* 提醒频率可配置

---

### 6.8 分享项目入口

* 将项目包配置导出为分享文件或链接
* 接收方可一键导入，快速复现相同的项目包结构
* 适合团队统一开发环境或同事间交接

---

## 💼 九、职业用户功能（律师 / 建筑师 / 设计师）

> 本章功能为**后期实现**，MVP 阶段不计入排期，但功能点完整规划。

### 9.1 职业预设模板

用户首次使用时可选择职业模板，预设分组结构与标签：

| 职业 | 默认分组 | 默认标签示例 |
|------|----------|-------------|
| 律师 | 进行中案件 / 已结案 / 待处理 / 归档 | 民事 / 刑事 / 合同 / 客户A |
| 建筑师 | 在建项目 / 方案阶段 / 竣工 / 归档 | 住宅 / 商业 / 方案 / 施工图 |
| 设计师 | 进行中 / 待确认 / 已交付 / 存档 | 品牌 / UI / 印刷 / 客户B |
| 开发者 | 工作 / 学习 / 个人 / 归档 | C# / Android / Web / Demo |
| 自定义 | 用户自定义 | — |

### 9.2 客户 / 联系人信息绑定

* 每个项目可关联一个或多个客户 / 联系人
* 联系人字段：姓名、电话、邮件、公司、备注
* 一键拨打电话（调用系统拨号）或发送邮件（调用系统邮件客户端）
* 支持按客户名称搜索项目
* 联系人可在多个项目间复用（联系人管理中心）

### 9.3 案件 / 项目文件结构管理

* 基于模板自动创建标准文件夹结构（如律师案件：合同 / 证据 / 庭审记录 / 往来函件）
* 支持自定义文件夹结构模板
* 文件夹结构创建后自动作为附件关联到项目

### 9.4 适配专业软件打开方式

* 建筑师：自动识别 `.dwg`（AutoCAD）、`.rvt`（Revit）、`.skp`（SketchUp）
* 设计师：自动识别 `.ai`（Illustrator）、`.psd`（Photoshop）、`.fig`（Figma 导出）
* 支持用户自定义添加任意专业软件后缀与打开方式

### 9.5 密码保护（职业场景强化）

* 涉密项目 / 分组加密保护
* 支持按项目单独设置密码或统一主密码
* 隐藏模式：锁定后对应条目完全不可见
